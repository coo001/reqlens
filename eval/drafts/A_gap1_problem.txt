RotaMate — fair chore rotas from a messy group chat

RotaMate is a small web app for shared houses. You paste the chore part of your house group chat, and RotaMate returns a weekly rota that names who does each task, on which day, and why the split is fair. Each housemate can then copy their own list.

How the AI works: RotaMate sends the pasted chat to the Gemini API in two steps. The first call extracts every chore commitment, swap, and excuse as structured JSON (person, task, day, source message). The second call proposes a rota from that list. Our own code then checks the proposal: every task must appear exactly once per week, nobody may get more than two extra tasks, and every assignment must point back to a real message in the chat. If a check fails, the app shows the problem instead of a rota.

Demo: the demonstration video walks through one real-looking chat from paste to finished rota in under three minutes: https://youtu.be/rotamate-demo (unlisted, no login needed).

Source code and setup: the code is public at https://github.com/example/rotamate. The README explains how to run it locally with Node 20 and where to place your own free Gemini API key in a local environment file that is never committed.

Built with and credits: Next.js and React for the interface, the Gemini API for the two AI calls, Zod for checking the JSON shape, and the open-source date-fns library for day handling. The house chat in the demo is invented for this submission.

AI tools we used while building: we used an AI coding assistant to draft the first version of the JSON checking code and the CSS layout. We wrote the prompts, the fairness rules, and the source-message check ourselves, and we tested the assistant's checking code against ten chats where we knew the correct answer; it missed swaps that happened across two messages, so we rewrote that part by hand.
